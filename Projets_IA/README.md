# 🤖 Projets IA — Intelligence Artificielle & Code Source

Ce dossier regroupe les projets liés à l'intelligence artificielle développés dans le cadre d'AsArt'sDev.

## Projets

### Génération d'Illustrations
Utilisation de modèles d'IA générative pour créer les illustrations du livre "Les trois vies de Asmir".

### Assistant Narratif
Outil d'aide à l'écriture basé sur des modèles de langage pour enrichir les récits autobiographiques.

### Plateforme E-commerce
Application React intégrant des fonctionnalités intelligentes pour la présentation et la vente de livres en ligne.

## Technologies

- Python (scripts IA et automatisation)
- JavaScript / React (interfaces web)
- API de modèles de langage et d'image
- Git pour la gestion de versions

## Structure du Code

```
Projets_IA/
├── generation_illustrations/   # Scripts de génération d'images
├── assistant_narratif/         # Outil d'aide à l'écriture
└── outils_divers/              # Utilitaires et scripts annexes
```
