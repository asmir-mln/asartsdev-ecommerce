# 🎨 Portfolio — Demande de Subvention

Ce dossier contient les documents préparés dans le cadre d'une demande de subvention pour le projet AsArt'sDev.

## Contenu

- Dossier de présentation du projet
- Budget prévisionnel
- Plan de développement artistique
- Lettres de motivation et de recommandation

## Objectifs du Projet

Le projet AsArt'sDev vise à :

1. Publier une collection de livres illustrés pour enfants
2. Développer une plateforme numérique de diffusion
3. Intégrer l'intelligence artificielle dans la création artistique
4. Rendre la culture accessible au plus grand nombre

## Destinataires

Ce portfolio est destiné aux organismes de financement culturel, fondations et institutions soutenant la création artistique et numérique.
