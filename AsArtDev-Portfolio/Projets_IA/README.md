# Projets_IA — AsArtsDev

Ce dossier contient les exemples de code et la documentation des projets d'intelligence artificielle développés dans le cadre d'AsArtsDev.

## 🤖 Description

Projets d'IA développés par Asmir Milianni, combinant apprentissage automatique, traitement du langage naturel et génération de contenu artistique.

## 📁 Fichiers

| Fichier | Description |
|--------|-------------|
| `code_exemple.py` | Exemple de code Python illustrant les techniques d'IA utilisées dans le projet |

## 🛠️ Technologies utilisées

- **Python 3** — langage principal
- **scikit-learn** — machine learning
- **transformers (HuggingFace)** — traitement du langage naturel
- **PIL / Pillow** — traitement d'images

## 🎯 Applications

- Génération assistée de récits et dialogues
- Aide à la création d'illustrations
- Analyse de textes autobiographiques
- Classification et organisation de contenus
