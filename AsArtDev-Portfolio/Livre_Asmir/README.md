# Livre_Asmir — Les 3 Vies d'Asmir

Ce dossier contient le livre illustré autobiographique **"Les 3 Vies d'Asmir"**.

## 📖 Description

Roman illustré en cours de finalisation, basé sur des souvenirs personnels de l'auteur Asmir Milianni. Le livre retrace trois périodes fondatrices de sa vie à travers un récit illustré et enrichi de personnages symboliques.

### Contenu du livre :
- **Couverture et logo AsArtsDev** — identité visuelle du projet
- **Illustrations originales** — une par chapitre/page clé
- **Personnage Sheitan** — figure narrative symbolique du livre
- **Aides bienveillantes** — personnages accompagnateurs dans le récit
